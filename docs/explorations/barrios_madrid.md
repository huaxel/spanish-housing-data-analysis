# Madrid por barrios: el registro confirma la brecha

> Added 2026-10-07. `barrios_madrid` mirrors the Ayuntamiento Banco de
> datos serie 0504020100060 (Colegio de Registradores declared prices,
> ~96–98% coverage): 153 barrios × 2007–2025 × Total/Nuevas/Usadas
> (8,721 rows, 3,546 suppressed nulls — barrios publish only with 15+
> cases). Fetched by replaying the bank's session query builder; the
> value catalog is parsed dynamically so new years cannot silently drop.
> Registry transaction values — compatible with valor tasado levels,
> not with offer prices (the Barcelona Idealista barri series stays out:
> offer-based and dead since 2018).

## What this does not show

No rents, no vacancy, no population at barrio grain — prices only, and
only Madrid: no other city publishes official barrio transaction prices.
